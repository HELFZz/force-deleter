# ForceDeleter

Принудительное удаление файлов и папок в Windows. Обходит «Отказано в доступе», атрибуты read-only/hidden/system, длинные пути (> 260 символов), junction/симлинки и занятые файлы.

[**Скачать ForceDeleter.exe**](https://github.com/HELFZz/force-deleter/releases/latest) · Windows 10/11 · .NET Framework 4.8 (уже встроен в систему)

## Установка

1. Скачайте `ForceDeleter.exe` из раздела **Releases**.
2. Запустите его. Программа установится в `%LOCALAPPDATA%\Programs\ForceDeleter`, добавит пункт в контекстное меню Проводника, включит автозапуск и запустит фоновый агент в трее. Один раз нужно подтвердить UAC.
3. Правый клик по файлу или папке → **«Удалить в любом случае»**.
   В Windows 11 пункт находится в **«Показать дополнительные параметры»** (или `Shift+F10`).

Повторный запуск скачанного exe обновляет установленную версию. Чтобы запустить без установки, используйте `ForceDeleter.exe --tray`.

### Удаление программы

Параметры Windows → Приложения → Установленные приложения → **ForceDeleter** → Удалить.

Либо вручную:

```bat
"%LOCALAPPDATA%\Programs\ForceDeleter\ForceDeleter.exe" --uninstall
```

Удаляются пункт меню, автозапуск, фоновый агент и папка программы. Журнал и настройки в `%LOCALAPPDATA%\ForceDeleter` остаются — при необходимости удалите эту папку вручную.

## Возможности

- Восстановление прав через смену владельца и сброс/выдачу ACL.
- Удаление read-only, hidden, system файлов и папок.
- Длинные пути (prefix `\\?\`), в том числе вложенные деревья длиннее 260 символов.
- Junction и симлинки: удаляется сама ссылка, цель не затрагивается.
- Занятые файлы: удаление при следующей перезагрузке через `PendingFileRenameOperations` (можно отключить в настройках).
- Множественное выделение в Проводнике.
- Фоновый агент работает с правами администратора, поэтому удаление из меню не требует UAC каждый раз.
- Уведомления о результате и журнал.

## Настройки

Двойной клик по иконке в трее:

- пункт «Удалить в любом случае» в контекстном меню;
- удаление занятых файлов после перезагрузки;
- уведомления;
- автозапуск при входе в систему (задача планировщика с повышенными правами).

Журнал: `%LOCALAPPDATA%\ForceDeleter\ForceDeleter.log`.

## Командная строка

```text
ForceDeleter.exe                     установка/обновление и запуск агента
ForceDeleter.exe --tray              портативный запуск без установки
ForceDeleter.exe --install           принудительная установка/переустановка
ForceDeleter.exe --uninstall         полное удаление
ForceDeleter.exe --delete <путь>     удалить через фоновый агент
ForceDeleter.exe --delete-local <путь>  удалить в текущем процессе (нужны права)
ForceDeleter.exe --exit              остановить фоновый агент
```

## Требования

- Windows 10 (1903+) или Windows 11, x86/x64.
- .NET Framework 4.8 — входит в состав Windows 10/11, отдельно ставить ничего не нужно.
- Права администратора для защищённых объектов (агент запрашивает UAC при установке и запуске).

## Сборка

Нужен только встроенный в Windows компилятор C# (.NET Framework 4.x), без Visual Studio и .NET SDK:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат: `dist\ForceDeleter.exe`.

## Важно

- Удаление **без корзины**. Восстановить файлы после удаления нельзя.
- Программа отказывается удалять корни дисков (`C:\`, `D:\` и т.п.).
- Системные и защищённые антивирусом файлы могут остаться, если их блокирует ядро ОС или драйвер.
- Используйте на свой риск; перед удалением важных данных сделайте резервную копию.
